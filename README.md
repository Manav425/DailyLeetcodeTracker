## How It Works

Solutions are automatically added to this repository after an accepted LeetCode submission.

The automation works as follows:

1. I solve and submit a problem on LeetCode.
2. The tool checks my recent accepted submissions using LeetCode's GraphQL API.
3. It retrieves the submitted code and problem details.
4. It organizes the solution using the problem number and title.
5. It uses the GitHub API to automatically commit the solution to this repository.

This removes the need to manually upload or commit each solution.
