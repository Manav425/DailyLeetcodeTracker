<h1>Daily Leetcode Tracker</h1>
An automated tool that tracks my daily LeetCode progress.

How it works
<ul>
<li> I solve and submit a problem on LeetCode.</li>
<li> The tool checks my recent accepted submissions using LeetCode's GraphQL API.</li>
<li> It retrieves the submitted code and problem details.</li>
<li> It uses the GitHub API to automatically commit the solution to my DailyLeetcodeTracker repository.</li>
</ul>

This removes the need to manually upload or commit each solution.
