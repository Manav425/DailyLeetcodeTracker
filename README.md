<h1>Daily Leetcode Tracker</h1>
An automated tool that tracks my daily LeetCode progress.

How it works
I solve and submit a problem on LeetCode.
The tool checks my recent accepted submissions using LeetCode's GraphQL API.
It retrieves the submitted code and problem details.
It uses the GitHub API to automatically commit the solution to my DailyLeetcodeTracker repository.

This removes the need to manually upload or commit each solution.
